# Review Checklist

The reviewer agent must check:

- The task objective was satisfied.
- The diff is scoped to the task.
- Project context and coding rules were followed.
- Tests or checks were run when relevant.
- No secrets or credentials were introduced.
- Main branch was not modified directly.
- Auth, payments, secrets, database, infrastructure, and production behavior changes require human review.
- UI changes match the compact dark KAVBAN visual language.
- Remaining risks are clearly listed.
